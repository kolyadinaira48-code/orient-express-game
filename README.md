# Убийство в Восточном экспрессе: Последнее путешествие

Консольная детективная игра на Python. 18 ноября 1934 года в Восточном экспрессе
убит предприниматель Адриан Рид, а «Синяя книга» с доказательствами мошенничества
исчезла. Игрок помогает детективу: изучает документы и вводит регулярные выражения.
Программа проверяет шаблон на скрытых данных; при успехе выдаёт улику, при ошибке
показывает контрпример и разрешает повторить ввод.

## Правила

Игра состоит из трёх глав по два раунда. Метод проверки зависит от раунда:
`re.fullmatch()` (раунды 1 и 5), `re.finditer()` (раунды 2 и 3), `re.sub()` (раунды 4 и 6).
Принимается любой шаблон, который верно проходит все тесты. Команды: `?` (подсказка),
`выход`. Шаблон вводится без кавычек и без префикса `r`. Синтаксическая ошибка
(`re.error`) отличается от верно записанного, но неверного шаблона: во втором случае
показывается конкретный контрпример.

## Запуск

```
python main.py
python run_tests.py      # или: python -m pytest
```

Нужен Python 3.9+, сторонние библиотеки не требуются.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | запуск, игровой цикл, журнал улик |
| `core.py` | интерфейс раунда `check(pattern) -> (успех, сообщение)` |
| `characters.py` | персонажи |
| `story.py` | общие сюжетные тексты |
| `chapter_1.py` | глава I «Список пассажиров» (раунды 1–2) |
| `chapter_2.py` | глава II «Ночь убийства» (раунды 3–4) |
| `chapter_3.py` | глава III «Последние доказательства» (раунды 5–6) и финал |
| `tests/` | assert-проверки по главам |
